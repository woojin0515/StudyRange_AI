# MVP Scope

## In Scope

- User authentication (basic)
- Workspace creation
- Exam range input and validation
- File upload (textbook PDF, worksheet, notes)
- Processing status view
- Range-to-content mapping result view

## Out of Scope (MVP)

- Quiz generation
- Summary generation
- Flashcard generation
- Parent/teacher role features

## Exit Criteria

- Each in-scope flow works end-to-end in deployable form
- Minimum reliability/observability baseline documented
